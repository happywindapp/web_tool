# One Editor: ngân sách file chính (≤ 9,9 MB từ 2026-11-22; trước 1 MB, 700 KB) → bundle nạp lười; script vendor build lại core

**Triệu chứng.** Thêm tính năng vào One Editor làm `tools/one-editor.html` vượt 700 KB (ngân sách phase 6). Chạy `scripts/vendor-one-editor-libraries.ps1` để thêm 1 gói (Vim / Emmet) làm `tools/vendor/codemirror-6.43.15/codemirror-core.min.js` + `codemirror-languages.min.js` đổi hash dù không đổi phiên bản.

**Ngân sách hiện hành (user chốt 2026-11-22, mọi tool / project; thay mức 1 MB của 2026-11-21).** File chính ≤ 9,9 MB raw · mỗi file phụ nạp lười (bundle code của mình) ≤ 9,9 MB raw, **tối đa 3 file phụ / tool** (thư viện `tools/vendor/…` và trang sandbox CSP riêng không tính) · sẵn sàng khi giả lập CPU chậm 4× ~2 s chỉ là mức cảnh báo. Vượt trần ⇒ hỏi user, không tự nâng. Số đo nền: `browser-js-parse-cost-and-syntax-check-cost-measured.md`.

**Nguyên nhân.** File chính đã ~700 KB sau phase 8. Script vendor cài lại mọi gói, phụ thuộc bắc cầu (`@lezer/*`, `style-mod`…) được resolve bản mới hơn.

**Cách xử lý đúng.**
- Tính năng ít dùng ⇒ đặt module trong `src/one-editor/<bundle>.template.js` (build script ghép `*.template.js` → `tools/<bundle>.js`), nạp bằng `VendorPaths.load` lúc dùng; pane đăng ký `PreviewPane.addView`; chuỗi EN của module lazy để trong file i18n riêng `@include` vào chính bundle. Từ 2026-11-21 chỉ còn **1 bundle** `one-editor-extras.js` (data tools + FIX dictionary/detail + power tools, `VendorPaths.load("extras")`); thêm tính năng ít dùng ⇒ `@include` vào `one-editor-extras.template.js`, không tạo bundle mới trừ khi bundle vượt 1 MB. Editor extras (bộ phím, aids, Outline, snippet, phiên, khoá ghi chú, lịch sử) đã inline vào file chính — module inline **không được** chạm `CM` lúc định nghĩa (CodeMirror nạp sau) ⇒ class `extends CM.…` phải tạo lười (xem `Swatch()` trong `editor-visual-aids.js`).
- Test node không nạp bundle ⇒ `node --check` mọi `src/one-editor/js/*/*.js` trước khi kiểm trình duyệt.
- Chỉ thêm gói vendor: chạy script rồi `git checkout -- tools/vendor/codemirror-6.43.15/codemirror-core.min.js tools/vendor/codemirror-6.43.15/codemirror-languages.min.js`, kiểm hash các file khác không đổi.
- Bẫy gặp ở phase 9 (2026-11-21): CSS của bundle ⇒ `@include styles/x.css` trong `*.template.js` (build chèn `<style>` khi bundle chạy); file JS được `@include` không được chứa chữ `<script` (build từ chối) ⇒ ghép `"scr" + "ipt"`; view của pane **không** được có field `error` (PreviewPane.show coi là lỗi cả pane) ⇒ đặt tên khác (`failed`); tham số op theo tab cần sống qua F5 ⇒ lưu ở `doc.link.opts` của tab kết quả (document-store + HotExit giữ), link / demo đặt sẵn phải ghi vào đó khi tab kết quả đã tạo; op cần syntax tree phải `await LangLoader.apply(src)` (gói ngôn ngữ nạp lười).
