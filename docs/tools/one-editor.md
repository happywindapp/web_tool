## 1. Mục đích

Trình soạn code + text chạy hoàn toàn trên trình duyệt, gộp VS Code · Sublime Text · Notepad++ · online notepad: nhiều view, tab, ghi chú tự lưu,
mở/lưu file + folder trên máy, nhận diện ngôn ngữ, format / chuyển đổi / so sánh, bộ Notepad++ (bảng mã, EOL, thao tác dòng, macro, file lớn),
preview sơ đồ / chart / Markdown / HTML cạnh code, tìm / thay trong nhiều file, xuất / in, dịch + đọc to + từ điển tiếng Anh; phase 8: công cụ dev (JWT, URL, epoch, lịch sử cục bộ), dữ liệu (cây, JSONPath / XPath, lint, Rainbow CSV), log + FIX (lọc, tail -f, hover), thao tác editor (Outline, Goto Anything, bộ phím + Vim, Emmet, snippet, phiên, mật khẩu). v1 = phase 0 → 1 → 2 → 3 → 6, rồi phase 7 (dịch); **Cloud chưa có — phase 4–5 hoãn** (ADR #19).

Phím trình duyệt giữ (`Ctrl+N/T/W/Shift+T`, `Ctrl+1…8`, `Ctrl+Shift+R`) ⇒ dùng biến thể `Alt`. `Ctrl+K` là phím chord (chờ 1,5 s phím thứ 2).
Xuất (tải xuống / .txt / in / Copy as HTML) không có phím — mở qua Palette (`Ctrl+P` đã là Quick Open; In của trình duyệt cũng chỉ in nội dung tab).

## 5. Luật nghiệp vụ

- **"Chạy ở view nào ⇒ kết quả ở view kia"** qua tab kết quả liên kết (`OutputLink`): chạy lại cập nhật đúng tab đó, không bao giờ đè tab file; tab kết quả sửa tay thì ngừng tự cập nhật, ▶ hỏi trước khi ghi đè, đóng thì giữ thành ghi chú. Mọi tự sửa đẩy vào `fixes` ⇒ lint mark trên tab nguồn.
- **Find in files** (`FindCore` thuần + `FindSources` + `FindReplace` + `SideBar`):
  - Phạm vi: tab đang mở + mọi ghi chú + folder Explorer (ô "Folder"); bỏ clone, tab preview, hex, file > 50 MB đang xem theo đoạn. File folder đã mở thành tab chỉ tính 1 lần.
  - Giới hạn (áp cho file đọc từ đĩa: folder + tab chưa đọc lại; tab đang mở tới 50 MB vẫn được quét): bỏ `.git` + `node_modules` (ô tick để gồm), file > 5 MB, file nhị phân (đuôi ảnh/zip/exe/pdf/font… hoặc byte NUL trong 8 KB đầu); ≤ 20.000 file duyệt; hiện 2.000 kết quả đầu; đếm ≤ 100.000 khớp/file (hiện "≥"). Mọi thứ bị bỏ / lỗi / folder bị cắt ở 5.000 mục hiện trên dòng trạng thái của panel (tooltip liệt kê ≤ 20 file lỗi / tab cần cấp quyền).
  - Nguyên từ hiểu chữ có dấu (Latin-1 Supplement → Latin Extended-B + Latin Extended Additional); chế độ thường chỉ đặt biên ở phía query bắt đầu/kết thúc bằng chữ (như VS Code), chế độ regex luôn đặt cả 2 phía; không dùng flag `u` để giữ cú pháp regex của người dùng.
  - Thay: chế độ regex hỗ trợ `$1…$99`, `$<tên>`, `$&`, `` $` ``, `$'`, `$$`, `\n`, `\t`, `\\` (chế độ thường thay nguyên văn); khớp được tìm lại trên nội dung hiện tại; mỗi tab 1 transaction (Ctrl+Z); file chưa mở được thêm vào view đang chọn (không đổi tab đang xem); **không ghi đĩa** — người dùng tự Ctrl+S.
- **Xuất**: tải xuống dùng cùng `LocalFs.encode` như Lưu (bảng mã, EOL, BOM của tab); tab hex / file lớn bị từ chối. In dựng `#printOut` từ toàn bộ văn bản (CodeMirror chỉ vẽ dòng đang thấy), tô màu theo theme sáng; quá 2 MB thì không tô màu. Copy as HTML: vùng chọn (không chọn ⇒ cả tab), `<pre>` style inline (mail / Word bỏ `<style>` và class), màu theo theme đang dùng.
- **Encoding**: ký tự không có trong bảng mã khi lưu ⇒ báo dòng/cột, không ghi; không tự đổi bảng mã.
- **Đổi trên đĩa** (`DiskSync`, `js/workbench/disk-change-sync.js`):
  - Mốc = `{size, lastModified}` của tab file có handle, ghi lúc mở / đọc lại / lưu / đổi tên trong Explorer; đi theo tab qua hot exit (F5) và Ctrl+Shift+T. Kiểm = `handle.getFile()` so mốc (không đọc nội dung); bỏ tab đang lưu, file lớn xem theo đoạn, tab đang tail -f. Không có mốc (phiên cũ): tab sạch so theo nội dung, tab có thay đổi lấy mốc hiện tại.
  - Khi chạy: 🔄 (toolbar, Explorer, lệnh "Làm mới từ đĩa") = mọi tab file **kể cả tab chưa đọc lại sau F5** (đã có quyền thì đọc luôn, chưa có ⇒ cú bấm 🔄 hỏi quyền ngay; file chưa được cấp ⇒ thông báo bấm để cấp quyền; bấm vào vùng soạn của tab chưa đọc lại cũng hỏi quyền) + đọc lại folder đang mở, báo cả khi không có gì đổi. `focus` / `visibilitychange` chỉ kiểm tab; sự kiện `FileSystemObserver` (folder Explorer đệ quy + từng file đang mở) kiểm tab + folder; cả hai debounce 300 ms, chạy im lặng — chỉ báo khi có tin mới. Lần kiểm đến lúc đang kiểm ⇒ xếp hàng chạy 1 lần sau đó. Làm mới folder giữ node cũ (trạng thái mở, nút trên dòng), chỉ vẽ lại khi cây đổi.
  - Tab sạch đổi trên đĩa (≤ 50 MB, hoặc tab hex) ⇒ tự đọc lại bằng 1 transaction riêng (`isolateHistory`: Ctrl+Z lấy lại bản cũ; con trỏ / clone giữ nguyên; giữ bảng mã; cập nhật EOL / BOM kể cả khi chỉ EOL đổi); gõ trong lúc đang đọc ⇒ không thay, chuyển sang ⚠. Tab sạch > 50 MB ⇒ chỉ báo mở lại file. Tab có thay đổi chưa lưu ⇒ không đụng nội dung, gắn ⚠ ở tab + Explorer + status bar, thông báo bấm được ⇒ chọn: **Đọc lại** (bỏ bản của tôi, Ctrl+Z được) / **Giữ bản của tôi** (mốc = đĩa hiện tại) / **So sánh** (bản đĩa mở tab tạm chỉ đọc ở view kia + Compare).
  - File biến mất (`NotFoundError`) ⇒ tab giữ nội dung, bỏ handle, thành chưa lưu (như xoá trong Explorer). Lỗi khác (chưa cấp quyền…) ⇒ bỏ qua im lặng.
  - **Lưu**: đĩa khác mốc ⇒ `confirm` ghi đè; Huỷ ⇒ không ghi, thông báo bấm được để chọn như trên. Lưu xong ⇒ mốc mới, bỏ ⚠.
  - Folder: chỉ đọc lại các folder **đang mở** (giữ trạng thái mở), folder đóng đọc lại khi mở; folder kéo-thả / chọn qua input (không handle) không làm mới được.
- **Trạng thái Git** (`GitStatus` + `GitStatusModel` + `GitHandleFs`):
  - Repo = folder có handle mà danh sách con có **thư mục** `.git` (gốc hoặc folder con đã mở ⇒ mở folder chứa nhiều repo cũng được, repo lồng nhau lấy repo gần nhất); `.git` là file (worktree / submodule trỏ ra ngoài) ⇒ bỏ qua. isomorphic-git 1.44.11 (`tools/vendor/isomorphic-git-1.44.11/`, kèm polyfill `buffer` truyền vào như tham số — không tạo `window.Buffer`) nạp lười khi gặp repo đầu tiên.
  - **Chỉ đọc**: `statusMatrix({ refresh: false })` + adapter ném `EROFS` cho mọi lệnh ghi ⇒ không bao giờ ghi `.git/index`. File có `size` + mtime (ms) khớp index ⇒ dùng lại stat của index (stat cache như git, độ phân giải ms) ⇒ không băm; còn lại băm nội dung (theo `core.autocrlf`). Đo: `web_tool` 881 file ~0,5 s, chỉ đọc file đã sửa + `.gitignore`; `HSC_STP` (pack 28 MB) 0,17 s; khớp `git status --porcelain -uall`.
  - Mã: `[head, workdir, stage]` ⇒ c / m / a / d (`git rm --cached`, file còn trên đĩa) / u; file không có trong kết quả ⇒ bị ignore; folder = mức mạnh nhất bên trong (m > c > u), không có gì ⇒ ignore / rỗng. `.git` và bên trong không gắn trạng thái; folder có `.git` là **file** (submodule / worktree) và mọi thứ bên trong cũng không. Packfile tổng > 300 MB ⇒ không quét (isomorphic-git đọc cả pack vào RAM), báo 1 lần. Không giữ cache giữa các lần quét (đọc lại pack mỗi lần — RAM chỉ tăng trong lúc quét).
  - Quét lại: 🔄 / `FileSystemObserver` (sau khi đọc lại folder), tạo / đổi tên / xoá / dán / giải nén trong Explorer, quay lại cửa sổ (`focus`, debounce 800 ms — vd sau khi commit bằng TortoiseGit), sau khi Lưu file; lần quét đến lúc đang quét ⇒ chạy lại 1 lần sau đó; chỉ vẽ lại cây khi kết quả đổi. Repo mất `.git` / không còn trong cây ⇒ bỏ khỏi danh sách, không báo. Lỗi đọc (index v4, repo hỏng…) ⇒ báo 1 lần tới khi quét lại thành công, không hiện biểu tượng.
  - **Lệnh TortoiseGit**: chỉ chép (không chạy). Tên lệnh giữ đúng tên menu TortoiseGit (English) ở cả 2 ngôn ngữ. Đường dẫn gốc nhập tay, nhận `X:\…` (gốc ổ giữ `C:\`) hoặc UNC `\\máy\share…`, không có `"`; lưu localStorage `web_tool.one-editor.tgitRoots` theo tên folder gốc Explorer. `TortoiseGitProc.exe` phải có trong `PATH` (bộ cài TortoiseGit tự thêm `…\TortoiseGit\bin`).
- **Mở bằng ứng dụng / tab trình duyệt** (`LocalRoot` + `OpenWith` + `BrowserTab` + `OpenWithSetup`, ADR #25):
  - Đường dẫn thật dùng chung `tgitRoots` với TortoiseGit (đặt 1 lần cho cả hai). - **Dịch** (`Translate` + `TrChunk`):

- **Công cụ dev**: JWT chỉ giải mã trên máy, pane luôn ghi chữ ký chưa kiểm; text tab = JSON (F5 dựng lại pane từ text). Lịch sử cục bộ chụp text đúng lúc ghi, bỏ bản trùng (FNV-1a + độ dài), file nhận diện bằng `isSameEntry`; file không có handle (kéo-thả) dùng khoá theo tab ⇒ mở lại là lịch sử mới.
- **Cây / truy vấn**: chỉ tab JSON / XML / HTML (Plain Text thì dò nội dung); JSONPath trên AST tolerant (giá trị giữ text gốc, ≤ 5.000 kết quả, bước giữa ≤ 1.000.000 nút); XPath bằng `document.evaluate`, dòng nguồn chỉ gán khi phần tử DOM khớp phần tử nguồn (thuộc tính đầu) — HTML bị trình duyệt chèn / dời phần tử thì để trống dòng.
- **Lint**: linter của CM chạy 600 ms sau khi gõ, ngôn ngữ linter quản thì FixMarks chỉ yêu cầu lint lại (không ghi đè dấu lỗi); dữ liệu > 5 MB tắt, code > 256 KB tắt (500 KB ở CPU 4× mất ~1–1,5 s mỗi lần). Phép ▶ Kiểm cú pháp cũng chỉ tự chạy lại khi nguồn ≤ 256 KB. Không nạp được bundle parser (hoặc trình duyệt chặn biên dịch WASM) ⇒ báo 1 lần trên status bar, tab không có dấu lỗi. Lỗi của Format / phép chạy chỉ nhường cho linter khi linter thật sự kiểm tab đó (code ≤ 256 KB, SQL không phải PL/SQL); còn lại FixMarks vẫn gạch như cũ. Tab TS / JSX lint lần đầu nạp plugin Prettier tương ứng (`typescript.js` 881 KB / `babel.js` 311 KB).
- **Tail -f**: mỗi 1 s, chỉ phần mới (`Blob.slice`), không vào undo, tab sạch vẫn sạch; file ngắn lại ⇒ đọc lại (tab có sửa chưa lưu ⇒ dừng); Ctrl+S ⇒ đồng bộ vị trí.
- **Phiên có tên**: lưu tab của mọi view (bỏ clone, pane), tab file sạch chỉ lưu handle, ghi chú theo id (ghi chú có mật khẩu không bao giờ lưu text); mở phiên = **thêm** tab, không đóng tab đang mở.
- **Ghi chú có mật khẩu**: hot exit mã hoá ngay trước khi ghi (bản mã giữ trong biến cục bộ của lần ghi, khoá chỉ trong bộ nhớ khi đang mở khoá); F5 / đóng trang ⇒ khoá lại, hiện chỗ giữ chỗ chỉ đọc; đặt mật khẩu ⇒ xoá các snapshot lịch sử cũ + text trong phiên đã lưu; "khoá lại ngay" đóng clone + tab kết quả / preview của ghi chú; không có snapshot lịch sử, phiên không mang text, tab kết quả không lưu text. Quên mật khẩu = mất nội dung. Link chia sẻ **thường** vẫn mang text của ghi chú đang mở khoá (người dùng tự chọn) — dùng link có mật khẩu.
- **Phase 9**: mọi op mới đi qua `OutputLink` (view kia, tự cập nhật khi gõ — trừ chạy code: chỉ khi bật "Chạy khi gõ"); tuỳ chọn mỗi tab nguồn ở `PowerTools.state` + `link.opts`. SQL chỉ là văn bản (tool không kết nối DB). Thay hàng loạt / sửa ký tự vô hình / bảng Markdown = 1 transaction (Ctrl+Z). Recipe dừng ở bước lỗi đầu, kết quả = bước tốt cuối. Dán TSV vào tab Markdown ⇒ bảng ở transaction thứ 2 (Ctrl+Z giữ TSV). Cron: luật OR của Vixie; Quartz 1 = CN (báo khi thứ dạng số).

## 9. Cloud

**Đăng nhập cloud (OAuth, ghi ngược lên cloud): chưa có — phase 4–5 hoãn** (chờ đăng ký Google Cloud + Entra; ADR #19). Provider tách ở `js/providers/` (`NotesDb`, `LocalFs`, `CloudDrive`); thêm cloud = thêm provider mới + nối vào Explorer / FileOpen / lưu.

**Folder công khai từ link (ADR #23 — OneDrive đọc + ghi, Google Drive chỉ đọc; `CloudDrive`, `js/providers/cloud-drive-public-folder-provider.js`)** — nút "☁ Mở từ link Drive / OneDrive…" ở mục Folder của Explorer, menu Mở và Palette "☁ Mở folder từ link Google Drive / OneDrive…":

- **Google Drive**: link `drive.google.com/drive[/u/N]/folders/<id>` hoặc `open?id=` ⇒ Drive API v3 (`www.googleapis.com`) với **API key của người dùng** (miễn phí, không cần billing; lần đầu `prompt` hỏi, lưu localStorage `web_tool.one-editor.gdriveKey`, đổi / xoá qua Palette "Google Drive: đổi / xoá API key…"). Folder phải chia sẻ "Anyone with the link". Gửi referrer mặc định để key giới hạn theo HTTP referrer vẫn dùng được (trên `file://` không có referrer ⇒ key phải không giới hạn referrer). Google Docs → `.txt`, Sheets → `.csv` (export); Slides / Forms / shortcut báo không mở được.
- **OneDrive cá nhân**: `1drv.ms` / `onedrive.live.com` ⇒ `api.onedrive.com/v1.0/shares/u!<base64url>/driveItem?$expand=children`, folder con `drives/{driveId}/items/{id}/children`, token ẩn danh từ `api-badgerp.svc.ms` (**không có tài liệu chính thức**, có thể ngừng bất kỳ lúc nào; token chỉ gửi tới `api.onedrive.com`, 401 ⇒ lấy token mới 1 lần). Tải file qua `@content.downloadUrl` (`my.microsoftpersonalcontent.com`, hết hạn ⇒ xin link mới 1 lần). OneDrive công ty / SharePoint cần đăng nhập ⇒ báo chưa hỗ trợ. Địa chỉ thanh URL khi đang xem trang (`onedrive.live.com/shared?id=/personal/…`, không có `authkey` / `redeem` / `resid`) không chứa mã chia sẻ (API trả `Invalid shares key`, đọc theo đường dẫn ⇒ `Access denied`) ⇒ báo cách lấy link "Chia sẻ → Sao chép liên kết".
- **Lưu ngược (chỉ OneDrive)**: file mở từ folder OneDrive gắn `doc.remote = { kind: "onedrive", url (drives/{id}/items/{id}), sid, eTag }` (đi theo hot exit) ⇒ Ctrl+S `PUT …/content` với `If-Match: eTag` đã đọc; 412 ⇒ `confirm` ghi đè (từ chối ⇒ không ghi); 403 ⇒ link chỉ xem, dùng Lưu thành. Token mới phải gọi `shares/{sid}` 1 lần (redeem) rồi mới đọc / ghi `drives/…/items/…` được (không thì `accessDenied`) ⇒ `odFetch` tự redeem. Lưu thành trên máy bỏ `remote`. Google Drive: API key không ghi được ⇒ Ctrl+S hỏi rồi Lưu thành trên máy.
- **Tạo file / folder (chỉ OneDrive)**: folder OneDrive có `+📄` / `+📁` ⇒ file: `PUT …/items/{id}:/<tên>:/content?@microsoft.graph.conflictBehavior=fail` (rỗng, rồi mở thành tab gắn `remote`), folder: `POST …/children` `{ name, folder: {}, conflictBehavior: fail }`; trùng tên ⇒ 409 báo "Đã có", không ghi đè.
- **Đổi tên / xoá trên cloud không làm được**: đo 2026-11-22, token ẩn danh với link quyền sửa (`effectiveRoles: ["write"]`) nhận 403 `accessDenied` cho `PATCH` / `DELETE` (thử `If-Match`, đường dẫn `:/tên:`, `parentReference`, `shares/…`) dù tạo / ghi nội dung được ⇒ mọi item OneDrive có nút `↗` mở `webUrl` (`onedrive.live.com?cid=…&id=…`, chỉ nhận host này) để đổi tên / xoá trên OneDrive web rồi 🔄; `webUrl` mở đúng item khi đã đăng nhập tài khoản chủ folder, khách chỉ mở được qua link chia sẻ. Làm đủ cần đăng nhập Microsoft (OAuth, hoãn theo ADR #19). Google Drive không có nút nào; chỉ gốc folder có 📌 (mục ghim `{ kind: "cloud", name, link }` trong `meta.pinned`, bấm là mở lại từ link); file mở thành tab không handle (như kéo-thả). File > 50 MB từ chối (không tải). ≤ 5.000 mục / folder. 🔄 đọc lại danh sách folder từ mạng. Find in files không quét folder từ link (tránh tải cả folder) — báo trong lỗi của panel. Link của folder đang mở lưu localStorage `web_tool.one-editor.cloudRoot` ⇒ F5 tự mở lại (không hỏi key; lỗi ⇒ báo trên status bar); đóng folder / mở folder trên máy thì xoá. Folder trên máy vẫn không giữ qua F5.
- Mọi request `credentials: "omit"`; CSP `connect-src` thêm `https://www.googleapis.com https://api.onedrive.com https://api-badgerp.svc.ms https://my.microsoftpersonalcontent.com https://*.1drv.com`. Đo 2026-11-22: Drive API + OneDrive (`api.onedrive.com`, `api-badgerp`, `microsoftpersonalcontent`) đều trả `Access-Control-Allow-Origin`; `embeddedfolderview` / `uc?export=download` của Google không có CORS.

## 11. Giới hạn

- File > 50 MB chỉ đọc theo đoạn; file nhị phân chỉ xem hex 1 MB đầu. Tìm trong file: 1 file 5 MB khớp trong 1 lần (regex nặng kiểu catastrophic backtracking vẫn có thể treo — không có worker).
- File System Access (folder, ghi đè, Gần đây) chỉ Chrome/Edge; trình duyệt khác mở bằng input + tải xuống, folder kéo vào chỉ đọc.
- Làm mới từ đĩa: chỉ tab có handle (Chrome/Edge); tab có thay đổi chưa lưu từ phiên trước bản này (chưa có mốc) ⇒ thay đổi trên đĩa trong lúc đóng trang không được phát hiện. Ctrl+Z sau khi tự đọc lại file EOL hỗn hợp trả text cũ nhưng giữ EOL của bản đĩa. `FileSystemObserver` chỉ Chromium mới (Chrome 157 có, kể cả `file://`); không có ⇒ chỉ kiểm khi focus / 🔄. Folder rất lớn (vd `node_modules`) đang mở ⇒ mỗi lần làm mới đọc lại toàn bộ folder đang mở (≤ 5.000 mục / folder). Kiểm headless bằng OPFS (cùng interface handle) — chưa thử với ổ đĩa thật qua picker.
- Bookmark, màu tô token (Style token) và folder trên máy đang mở trong Explorer lưu qua F5 nhưng thường phải bấm "Mở lại" để cấp lại quyền đọc (folder kéo-thả thì không lưu được) (màu tô cũng không đi theo link chia sẻ / tab clone); kéo đổi tỉ lệ view chỉ ở màn > 900px; theme Mermaid chưa theo giao diện tối.
- Bookmark lưu theo số dòng: file bị sửa bên ngoài khi tab đang đóng ⇒ bookmark có thể lệch dòng (dòng vượt cuối file bị bỏ). File kéo-thả không có handle ⇒ đóng tab là mất bookmark; file đã đóng rồi mới đổi tên / chuyển chỗ ⇒ bấm vào mục bookmark báo không còn trên đĩa và xoá mục đó; tab tạm / output đóng (không giữ thành ghi chú) cũng mất. Bookmark không đi theo link chia sẻ; file lớn (xem theo đoạn) và tab hex không đặt bookmark được.
- Phase 12: panel Git **chỉ đọc** (không stage / commit / pull — chép lệnh TortoiseGit), chỉ thấy repo trong folder mở bằng File System Access (folder kéo-thả / Drive / OneDrive không đọc được `.git`), pack > 300 MB bỏ qua; Problems chỉ kiểm **tab đang mở** (không quét folder), bỏ tab code > 256 KB / dữ liệu > 5 MB; badge TODO chỉ cập nhật khi panel đang hiện, đổi folder gốc phải ↻; clipboard chỉ ghi khi chép **trong** One Editor (trang web không đọc clipboard hệ thống ngầm), không qua F5 trừ khi bật `clipKeep`.
- Chưa kiểm Firefox / Safari và máy điện thoại thật.
- Git: chỉ folder mở bằng File System Access và phải mở **đúng folder chứa `.git`** hoặc folder cha của nó (trang web không đi ngược lên folder cha). Không có trạng thái conflict; file đã xoá không hiện (chỉ folder cha báo !). Junction / symlink theo cách Chrome trả về. "Mở bằng ứng dụng": Chrome hỏi xác nhận mỗi lần mở app ngoài; HTML mở ở tab mới không nạp được css/js/ảnh đi kèm theo đường dẫn tương đối; `search-ms` mở khung kết quả tìm kiếm và có thể bị chính sách công ty chặn.
